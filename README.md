# gostanos/homebrew-tap

Homebrew formulae for [Small Print](https://smallprint.dev).

```sh
brew install gostanos/tap/smallprint
```

`smallprint` lists the MCP servers, agent skills and instruction files your agents use, checks them against a lock file, and reads Small Print's public record of what each one tells an agent. The command's source and guide are at https://github.com/gostanos/smallprint-action/tree/main/cli and https://smallprint.dev/cli.
